# ISO/IEC 27001:2022 ISMS Framework & AWS Cloud Audit Remediation

This repository contains the complete Information Security Management System (ISMS) documentation, compliance audit records, governance policies, and AWS technical evidence for the Cybersecurity Clinic[cite: 1, 2]. The project demonstrates end-to-end alignment with ISO/IEC 27001:2022 standards across internal self-assessments, external peer evaluations, and hands-on AWS security remediations[cite: 1, 2].
